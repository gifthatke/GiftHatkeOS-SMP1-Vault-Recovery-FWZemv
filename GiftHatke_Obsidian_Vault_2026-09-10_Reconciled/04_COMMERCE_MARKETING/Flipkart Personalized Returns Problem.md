# Flipkart Personalized Returns Problem

## Incident/business problem
At one point the user reported:
- **18 Flipkart orders received**;
- all were sent/customized;
- they were then canceled/returned;
- the products became a direct loss because they were customer-specific;
- Flipkart was showing **7-day returns**.

## Core risk
A standard return policy can be economically destructive for made-to-order personalized goods.

## Required operating response
Track this as a marketplace policy/compliance problem, not merely customer-service leakage:
- verify correct product category/return settings;
- make personalization/non-resellable nature explicit where platform rules permit;
- preserve customer approval/personalization evidence;
- monitor cancellation timing before production;
- maintain marketplace-specific SOPs.
