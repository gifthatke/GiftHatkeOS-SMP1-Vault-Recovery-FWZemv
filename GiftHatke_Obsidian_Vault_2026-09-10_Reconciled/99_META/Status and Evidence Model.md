# Status and Evidence Model

Use these labels consistently:

| Status | Meaning |
|---|---|
| `certified-current` | Latest known certified truth for that scope |
| `certified-historical` | Valid historical certification, superseded for current-state decisions |
| `live-observed` | Seen working in production but not necessarily a full certification |
| `locked-governance` | Permanent or explicit TITAN LOCK rule |
| `planned` | Approved direction, not implemented/certified |
| `open` | Unresolved issue, investigation or pending work |
| `marketing-snapshot` | Campaign/product/creative state at a particular time |
| `knowledge-snapshot` | Retained conversational knowledge; verify against authority for critical use |

## Source precedence
1. Certified Enterprise Canon
2. Frozen Apps Script reference
3. Certified standalone repository evidence
4. Live production evidence
5. Conversation knowledge
6. Suggestions/ideas

## Editing rule
When a newer certified state appears:
- do not delete the old note;
- mark the old note historical;
- link it to the superseding certification;
- update [[../00_HOME/Current Operating Snapshot]];
- add an entry to [[../10_REGISTERS/Decision Register]] and [[../09_TIMELINE/Gift Hatke Timeline]].
