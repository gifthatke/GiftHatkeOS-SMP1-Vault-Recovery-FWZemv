# Shipping and Returns

## Personalized-goods constraint
Customized items can be difficult or impossible to resell, so cancellations, RTO and returns create unusually high loss.

## Key operating controls
- correct customization confirmation before production;
- customer contact/OTP where appropriate;
- COD risk control / partial COD;
- platform-specific return policy;
- shipping tracking;
- clear exception handling.
