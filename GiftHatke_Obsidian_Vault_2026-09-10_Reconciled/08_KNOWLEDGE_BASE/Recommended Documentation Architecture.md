# Recommended Documentation Architecture

For each business module, maintain:
1. Overview
2. Roles & permissions
3. Daily workflow
4. Field/reference guide
5. SOPs
6. Exceptions and troubleshooting
7. Reports/KPIs
8. Admin/configuration
9. Integration/API notes
10. Release/certification history

## Suggested module sequence
Orders → Production → Inventory → Shipping → Finance → CRM/Customers → Dashboard/Reports → Users/Roles → Settings.
